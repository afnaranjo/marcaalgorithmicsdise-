# Checklist QA visual Algorithmics

## Identidad

- [ ] Paleta exacta.
- [ ] Montserrat.
- [ ] Logo oficial intacto cuando aplica.
- [ ] No se mezcló otra identidad.

## Concepto

- [ ] Existe una idea dominante.
- [ ] El visual demuestra el mensaje.
- [ ] La tecnología tiene propósito.

## Composición

- [ ] Jerarquía clara.
- [ ] Aire suficiente.
- [ ] Alineaciones ópticas.
- [ ] No hay elementos para rellenar.
- [ ] Funciona en móvil.

## Fotografía

- [ ] Fisonomía conservada cuando corresponde.
- [ ] Piel natural.
- [ ] Manos correctas.
- [ ] Postura posible.
- [ ] Mirada coherente con la acción.

## Montaje

- [ ] Perspectiva consistente.
- [ ] Escala consistente.
- [ ] Luz/temperatura consistentes.
- [ ] Sombras de contacto cuando aplican.
- [ ] Sin halos de recorte.
- [ ] Profundidad lógica.
- [ ] Pantallas e interfaces con perspectiva.

## Anti-IA

- [ ] No glow/neón genérico.
- [ ] No fondo sci-fi genérico.
- [ ] No objetos flotantes gratuitos.
- [ ] No UI fuera de pantallas.
- [ ] No simetría automática sin intención.
- [ ] No rostro sintético genérico.
- [ ] No gradiente `AI-tech` por defecto.

## Copy

- [ ] Hook corto.
- [ ] Sin saturación.
- [ ] CTA único cuando aplica.
- [ ] Datos temporales verificados.

## Privacidad/licencias

- [ ] Uso de fotos autorizado.
- [ ] Sin datos personales en displays.
- [ ] Assets con licencia/permiso.
- [ ] Sin secretos.

## Edición

- [ ] Si era una corrección puntual, no se modificó nada adicional.
