# Plantillas para redes

Organiza plantillas por audiencia o programa y formato: 1080×1350, 1080×1920 y 1080×1080. Una adaptación final debe recomponer jerarquía, imagen, texto y safe zones; no basta con recortar.

## Herramientas operativas

- `creative-brief.md`: brief antes de producir una pieza/campaña.
- `carousel-system.md`: continuidad y variación para carruseles.
- `design-qa-checklist.md`: gate de calidad antes de entregar/publicar.

Estas plantillas no sustituyen `docs/brand/ART-DIRECTION.md`, `COMPOSITION-AND-MONTAGE.md` ni las reglas de identidad.
