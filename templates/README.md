# Plantillas

Este directorio contendrá plantillas maestras reutilizables, no cada exportación producida. Cada plantilla debe incluir fuente editable, preview, formatos, audiencia, elementos fijos, elementos editables, CTA y estado.

Categorías iniciales: `social`, `campaigns`, `presentations`, `documents` y `video`. Se crearán únicamente cuando exista un archivo real y aprobado.
