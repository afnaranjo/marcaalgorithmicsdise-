# Colores oficiales Algorithmics

Esta carpeta contiene recursos visuales derivados únicamente de la paleta aprobada. La fuente ejecutable es `config/brand/colors.json`; la documentación completa está en `docs/brand/COLORS.md`.

Los cuatro colores de marca son:

- Púrpura Oscuro — Pantone 7664 C — `#602B7A`.
- Amarillo Septiembre — Pantone 122 C — `#FFD749`.
- Menta Fresca — Pantone 333 C — `#33DFC0`.
- Frambuesa — Pantone 184 C — `#F44C75`.

No extraigas valores desde capturas comprimidas ni uses el cuentagotas si están disponibles estos tokens exactos.
