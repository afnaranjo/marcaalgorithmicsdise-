# Referencia histórica — carrusel Python de 6 láminas

Estado: `APPROVED REFERENCE`  
Alcance: `PROGRAM / HISTORICAL`

## Por qué se conserva

Este carrusel fue utilizado como estructura narrativa de Python y aporta un patrón reusable de secuencia. Sus fechas, precios, teléfonos, sedes y edades históricas **no son datos vigentes**.

## Secuencia recuperada

### 1. Transformación / hero

Territorio: `CREAR > CONSUMIR`.

Mensaje histórico: “Tu hijo puede usar tecnología. También puede aprender a crearla.”

Función: promesa y cambio de perspectiva.

### 2. Qué aprende

Python como vehículo para lógica, proyectos y resolución de problemas.

Función: traducir el curso a resultados observables.

### 3. Cómo funciona

Modalidad/frecuencia como bloque independiente.

Función: responder una objeción operativa sin competir con el hook.

### 4. Duración / segmentación

Grupos o tiempos organizados según edad/nivel cuando estén confirmados.

Función: mostrar estructura y acompañamiento.

### 5. Oferta

Fecha de inicio + inversión como bloque comercial de alta claridad.

Función: convertir interés en intención.

### 6. Cierre

Resumen + ubicación/contacto/CTA.

Función: una acción final clara.

## Reglas reutilizables

- una idea dominante por slide;
- separar aprendizaje, modalidad, oferta y contacto;
- no meter todos los datos en portada;
- fotografía real cuando esté autorizada;
- variar composición sin perder sistema;
- los datos comerciales se vuelven a verificar en cada campaña.
