# Ejemplos

`approved/` contiene únicamente **patrones representativos aprobados**; `experimental/` puede contener exploraciones claramente etiquetadas; `reference/` conserva aprendizaje y reglas de manejo de referencias.

Una referencia visual no se convierte automáticamente en plantilla ni en asset reutilizable.

Cuando una pieza histórica contiene personas, menores, datos o recursos con licencia dudosa, preferir documentar el patrón de composición y la decisión en vez de versionar el archivo visual.

- `approved/composition-patterns.md`: estructuras validadas.
- `reference/historical-campaign-index.md`: aprendizajes recuperados por campaña.
- `reference/asset-handling.md`: criterio para decidir qué arte puede entrar al repo.
