# Patrones de composición aprobados

Estos patrones no son archivos para copiar literalmente. Son estructuras que demostraron funcionar y mantienen alcance explícito.

## Python — estudiante + laptop + copy lateral

Estado: `APPROVED`  
Alcance: `PROGRAM`

- estudiante real;
- laptop diagonal;
- código visible dentro del display;
- sujeto a un lado;
- espacio negativo al lado opuesto;
- título dominante;
- detalles secundarios separados.

Reusable: geometría, foco, credibilidad.  
No reusable: fecha, precio, teléfono u oferta antiguos.

## Tech Kids / Open House — estudiantes + proyectos

Estado: `APPROVED`  
Alcance: `CAMPAIGN`

- estudiantes como anclas visuales;
- proyectos visibles;
- espacio limpio para mensaje;
- objetos 3D subordinados;
- identidad Algorithmics.

Reusable: relación estudiante/proyecto, aire y alternancia izquierda/derecha.  
No reusable: datos de evento.

## Future Coders — protagonista + textura IA sutil

Estado: `APPROVED`  
Alcance: `CAMPAIGN`

- adolescente protagonista;
- background de programación/IA con presencia baja;
- tipografía grande;
- continuidad de carrusel sin repetir encabezado completo.

## Roblox — fotografía + mundo de juego

Estado: `APPROVED`  
Alcance: `CAMPAIGN`

- estudiante real;
- mundo Roblox como contexto;
- profundidad y oclusiones;
- no heredar estética neón de referencias externas;
- entrega sin texto cuando el pedido es solo montaje.

## Edición quirúrgica

Estado: `APPROVED`  
Alcance: `GLOBAL`

Una versión aprobada permanece bloqueada. Los cambios puntuales no reinician dirección de arte.
