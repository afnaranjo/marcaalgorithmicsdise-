# Workflow de redes sociales

1. Define si es orgánico o pagado.
2. Selecciona objetivo, audiencia, programa, formato y destino.
3. Escribe una hipótesis creativa y un hook dominante.
4. Diseña primero el formato principal.
5. Recompon 4:5, 9:16 y 1:1 según necesidad.
6. Alinea arte, copy, botón de plataforma y CTA.
7. Revisa en pantalla pequeña y confirma datos variables.
