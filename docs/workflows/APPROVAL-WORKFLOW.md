# Workflow de aprobación

Estados: `DRAFT` → `EXPERIMENTAL` o revisión → `APPROVED`; material reemplazado pasa a `DEPRECATED` o `ARCHIVED`.

Una expresión como “este sí” puede aprobar una pieza sin convertir cada detalle en regla global. Si la decisión es repetible, registra alcance, motivo y aplicación en la documentación correspondiente.

No publiques ni hagas push de cambios de marca, plantillas maestras, scripts o reorganizaciones sin revisión explícita.
