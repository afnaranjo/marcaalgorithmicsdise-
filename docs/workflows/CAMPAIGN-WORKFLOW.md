# Workflow de campaña

1. Identifica programa, edad, usuario, decisor, sede y objetivo.
2. Separa hechos confirmados de datos pendientes.
3. Define insight, promesa, mecanismo, prueba, objeción y CTA.
4. Propón territorios realmente distintos y recomienda uno.
5. Construye sistema de mensajes, dirección de arte y formatos.
6. Formula variantes que cambien una dimensión principal.
7. Define métricas sin prometer rendimiento.
8. Documenta la ruta aprobada y archiva solo ejemplos representativos.
