# Workflow de diseño

1. Clasifica pieza, audiencia, objetivo, canal, formato, CTA y entregable.
2. Revisa memoria, marca, programa, plantilla y ejemplos relevantes.
3. Verifica datos variables y licencias.
4. Define hook, jerarquía, retícula, tipografía, imagen y CTA.
5. Produce con activos oficiales y tokens.
6. Adapta cada formato mediante recomposición.
7. Revisa identidad, legibilidad, contraste, ortografía, safe zones y derechos.
8. Guarda solo fuente, plantilla o ejemplo con valor reutilizable.
