# Workflow de presentaciones

- Presentación Algorithmics: usa la marca documentada en este repositorio y una plantilla aprobada cuando exista.
- Presentación NID: usa `$crear-presentaciones-nid`; no cambies su formato bloqueado.
- Separa modelos comerciales, académicos y de eventos.
- Conserva fuente editable, preview y README cuando una presentación se convierta en plantilla.
- Revisa cada diapositiva a tamaño completo, desbordamientos, contraste, fuentes, notas y derechos antes de entregar.
