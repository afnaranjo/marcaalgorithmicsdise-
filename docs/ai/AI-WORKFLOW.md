# Workflow para IA

## Antes

1. Sincroniza y revisa Git sin destruir cambios locales.
2. Lee `AGENTS.md`, la memoria y las fuentes canónicas relevantes.
3. Busca activos, plantillas, prompts y ejemplos reutilizables.
4. Identifica audiencia, programa, objetivo, canal, CTA y datos variables.

## Durante

1. Separa hechos verificados, inferencias y propuestas.
2. Usa Montserrat, tokens y logos oficiales.
3. Protege datos personales y derechos de terceros.
4. Mantén una idea dominante y adapta la composición al formato.

## Después

1. Revisa el entregable a tamaño real.
2. Ejecuta los validadores.
3. Documenta solo aprendizajes estables.
4. Revisa `git status` y `git diff`.
5. No hagas commit ni push sin autorización.
