# Reglas de diseño asistido por IA

- Genera imágenes base sin lettering final cuando la tipografía deba ser exacta.
- Inserta logos oficiales después de generar la imagen; no pidas al modelo que los reconstruya.
- Compón titulares y CTA con Montserrat real en una herramienta determinista.
- Reserva desde el prompt el espacio negativo necesario para texto, logo y safe zones.
- No imites artistas vivos ni copies campañas protegidas.
- Trata el texto generado dentro de una imagen como boceto.
- Revisa anatomía, manos, pantallas, código, ortografía, marcas y artefactos antes de aprobar.
