# Skills del proyecto

Las skills detectables por Codex viven en `.agents/skills/`.

| Skill | Uso |
|---|---|
| `algorithmics-brand-designer` | Piezas visuales y control de identidad Algorithmics |
| `algorithmics-copywriter` | Copy para padres, niños, adolescentes y campañas |
| `algorithmics-social-media` | Publicaciones, carruseles, stories y reels |
| `algorithmics-campaign-designer` | Sistemas multiformato y variantes de campaña |
| `crear-presentaciones-nid` | Presentaciones educativas NID con formato bloqueado |

Algorithmics y NID son sistemas visuales distintos. Usa la skill que corresponda al entregable y no mezcles identidades.
