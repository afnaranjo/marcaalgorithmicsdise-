# Documentación

- `ai/`: memoria estable, reglas para agentes y catálogo de skills.
- `brand/`: identidad visual y decisiones de diseño.
- `content/`: audiencias, voz, copy y CTA.
- `programs/`: fichas por programa; los datos variables requieren verificación.
- `workflows/`: procesos reproducibles de diseño, campañas, redes, video y presentaciones.
- `privacy/`: protección de menores, uso de medios y activos de terceros.
- `setup/`: herramientas y configuración por sistema operativo.

Los valores ejecutables viven en `config/`; esta carpeta explica cómo y por qué se usan.
