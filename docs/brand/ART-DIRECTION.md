# Dirección de arte Algorithmics

Estado: `APPROVED`  
Alcance: `GLOBAL`

## Principio principal

La marca puede ser muy creativa sin parecer generada automáticamente.

**Una buena pieza de Algorithmics debe sentirse nueva en la idea y familiar en el ADN.**

## 1. Concepto antes de decoración

Antes del layout, escribir:

> Esta pieza comunica __________ mediante __________.

Si no se puede completar de forma específica, todavía no hay concepto.

Ejemplo correcto:

> Comunica “de jugar a crear” mostrando a un estudiante real trabajando sobre un entorno Roblox subordinado a la fotografía.

Ejemplo débil:

> Comunica programación con elementos tecnológicos.

## 2. Una sola idea dominante

El espectador debe saber qué mirar primero en menos de dos segundos.

Orden habitual:

1. hook;
2. visual protagonista;
3. beneficio/prueba;
4. dato comercial;
5. CTA;
6. marca.

El logo no necesita ser el objeto más grande para que la pieza sea Algorithmics.

## 3. Composición editorial

Preferir:

- asimetría controlada;
- bloques con relación clara;
- alineaciones ópticas;
- espacios negativos intencionales;
- cortes fotográficos profesionales;
- tensión entre lleno y vacío;
- elementos que guían la mirada;
- ritmo visual.

Evitar:

- centrar todo por inercia;
- colocar todo dentro de tarjetas;
- repetir cápsulas;
- llenar huecos con iconos;
- “hacer bonito” sin función.

## 4. Aire

El vacío es parte del sistema. Cuando un área no necesita un elemento, déjala respirar.

El espacio negativo puede reservarse para titular, CTA, fecha, copy posterior o continuidad de carrusel.

## 5. Escala y crop

Usar cambios de escala para jerarquía, no múltiples efectos.

Una figura puede entrar parcialmente fuera de cuadro. Una laptop puede ocupar primer plano si el código es importante. Un objeto 3D puede quedar recortado en borde si refuerza profundidad.

No hacer todos los elementos del mismo tamaño ni usar zoom sin intención.

## 6. Profundidad

Construir profundidad con:

- primer plano;
- sujeto;
- plano de acción;
- fondo;
- oclusión;
- sombras;
- desenfoque óptico según distancia.

No construirla con glow.

## 7. Fotografía

La fotografía debe sentirse observada, no posada.

Preferir manos trabajando, mirada a pantalla, interacción real, gestos espontáneos, cuerpo orientado a la acción y expresión natural.

El estudiante no tiene que mirar a cámara para “vender”.

## 8. Color

Usar el púrpura `#602B7A` como ancla de reconocimiento. Los acentos oficiales tienen función.

No cubrir toda fotografía con una capa morada solo para “hacerla de marca”. La integración cromática debe respetar piel, luz y volumen.

## 9. Tecnología

Debe existir como evidencia:

- código dentro de una pantalla;
- Scratch como proyecto;
- Roblox como entorno de creación;
- Python como lenguaje;
- interfaz como herramienta;
- prototipo como resultado.

No usar strings de código flotando por defecto.

## 10. 3D

Permitido cuando pertenece a una campaña aprobada, representa algo relevante, ayuda a profundidad, respeta paleta y tiene iluminación coherente.

Rechazado cuando llena espacio, compite con el estudiante, introduce otro estilo, parece un pack de stock o depende de neón/glow para funcionar.

## 11. Referencias externas

Una referencia sirve para estudiar composición, ritmo, crop, escala o relación figura/fondo. No autoriza copiar su identidad, paleta, tipografía, personajes, UI o assets.

Extraer el principio y reconstruirlo dentro de Algorithmics.

## 12. Criterio anti-IA

Antes de aprobar preguntar:

- ¿Podría pertenecer a cualquier academia tech?
- ¿El rostro parece sintético?
- ¿Hay objetos sin motivo?
- ¿El fondo dice “futuro” pero no cuenta nada?
- ¿Todo está perfectamente centrado?
- ¿Hay demasiados brillos?
- ¿La iluminación viene de direcciones incompatibles?
- ¿La tipografía parece añadida después?

Si la respuesta es sí, redirigir la pieza.

## 13. Arte dirigido, no prompt genérico

Cada campaña debe definir idea, protagonista, acción, entorno, composición, contraste, textura, luz, profundidad, rol del color y restricciones.

No usar “futurista, dinámico, tecnológico, premium, cinematic” como sustituto de dirección de arte.
