# Lenguaje gráfico

Estado: `APPROVED`  
Alcance: `GLOBAL`

Este archivo es el **índice corto** del lenguaje visual. No duplica las especificaciones avanzadas.

## Debe transmitir

Tecnología, creatividad, aprendizaje, exploración, proyectos, juego con propósito, curiosidad, autonomía y futuro.

## Principios esenciales

- Una idea dominante.
- Recorrido visual simple: hook → visual/evidencia → beneficio → CTA.
- Espacio negativo suficiente y lectura móvil.
- Asimetría controlada y jerarquía editorial.
- Fotografía natural y acciones reales.
- Pantallas con contenido intencional, legible y físicamente integrado.
- 3D, iconos o interfaces solo cuando apoyen el concepto.
- Color funcional; el púrpura ancla reconocimiento y los acentos cumplen una función.

## Evitar

- apariencia excesivamente corporativa, fría o universitaria;
- infantilización de adolescentes;
- exceso de texto, iconos, logos, tarjetas o colores;
- código ilegible usado solo como decoración;
- stock corporativo genérico;
- estética de IA genérica;
- copiar literalmente interfaces, paletas o campañas de terceros.

## Especificaciones relacionadas

- Dirección de arte y composición editorial: `ART-DIRECTION.md`.

**Regla:** creatividad alta, identidad estable, montaje creíble.
