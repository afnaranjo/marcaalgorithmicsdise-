# Lenguaje gráfico

Estado: `APPROVED` como dirección general.

## Debe transmitir

Tecnología, creatividad, aprendizaje, exploración, proyectos, juego con propósito y futuro.

## Composición

- Un hook dominante.
- Recorrido visual simple: promesa, evidencia o proyecto, CTA.
- Espacio negativo suficiente y contraste accesible.
- Pantallas con contenido intencional y legible.
- Recursos 3D, iconos o interfaces solo cuando apoyen la idea.

## Evitar

- Apariencia excesivamente corporativa, fría o universitaria.
- Lenguaje visual infantilizado para adolescentes.
- Exceso de texto, iconos, logos o colores.
- Código ilegible usado únicamente como decoración tecnológica.
- Copiar literalmente interfaces o campañas de terceros.
