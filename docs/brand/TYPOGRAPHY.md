# Tipografía

Estado: `APPROVED` para la familia; escala exacta por canal aún `PENDING VERIFICATION`.

## Familia oficial

Montserrat. Los archivos entregados por el usuario viven en `assets/brand/fonts/montserrat/` e incluyen fuentes variables y estáticas bajo SIL Open Font License 1.1.

## Roles base

| Rol | Peso recomendado | Uso |
|---|---|---|
| Display / hook | ExtraBold 800 o Bold 700 | Titulares breves y promesas dominantes |
| Heading | Bold 700 | Encabezados y secciones |
| Subheading | SemiBold 600 | Apoyo y jerarquía secundaria |
| Body | Regular 400 o Medium 500 | Lectura continua |
| CTA | Bold 700 o SemiBold 600 | Acción principal |

## Reglas

- Usa pesos estáticos cuando la herramienta no soporte fuentes variables de forma confiable.
- No falsifiques negritas o cursivas si existe el archivo correspondiente.
- Ajusta tamaño, interlineado y longitud antes de comprimir el texto.
- Revisa acentos, signos españoles, viudas, huérfanas, saltos y desbordamientos.
- Las escalas numéricas definitivas deben aprobarse por formato antes de registrarse como globales.
