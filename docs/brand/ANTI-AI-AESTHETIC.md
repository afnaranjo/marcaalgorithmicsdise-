# Protocolo anti-estética de IA

Estado: `APPROVED`  
Alcance: `GLOBAL`

## Regla

**El uso de IA no debe ser perceptible como estilo.**

## Señales que debemos eliminar

### Rostros

- piel plástica;
- ojos demasiado brillantes;
- sonrisa uniforme;
- simetría facial sintética;
- cabello modelado como masa;
- persona genérica sin identidad.

### Iluminación

- rim light en todos los bordes;
- luces azules/moradas sin fuente;
- múltiples direcciones de sombra;
- exceso de bloom;
- glow sobre piel.

### Fondo

- laboratorio del futuro genérico;
- pasillos sci-fi;
- bokeh sin lógica;
- humo volumétrico gratuito;
- partículas/sparks sin función;
- cables y hologramas de stock.

### Layout

- todo centrado;
- todas las secciones dentro de tarjetas;
- demasiadas pills;
- iconos aleatorios;
- cada palabra con un color;
- degradado morado-azul `AI-tech`;
- fondos cargados para compensar falta de concepto.

### Objetos

- cubos/hexágonos flotantes;
- 3D con materiales incompatibles;
- teclados/controllers flotantes;
- UI que no pertenece a ninguna pantalla;
- elementos repetidos para llenar.

## Qué usar en su lugar

- fotografía documental;
- composición editorial;
- cropping intencional;
- negativos amplios;
- sombras físicas;
- textura real sutil;
- una metáfora visual;
- una sola acción clara;
- props reales;
- referencias del programa;
- interfaces auténticas;
- contraste tipográfico.

## Test de genericidad

Oculta el logo. Si la pieza podría ser de una academia de inglés, una startup de IA, una marca gamer, una universidad o una tienda de laptops cambiando únicamente el texto, falta dirección de arte Algorithmics.

## Test humano

La pieza debe contener decisiones intencionales de encuadre, crop, vacío, superposición, escala, ritmo, contraste o narrativa.

No añadir irregularidad artificial. La intención humana no es “hacerlo imperfecto”; es tomar decisiones con criterio.
