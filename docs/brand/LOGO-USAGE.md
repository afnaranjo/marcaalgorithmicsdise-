# Uso del logotipo

Estado: `APPROVED` para los archivos recibidos; áreas de seguridad y tamaños mínimos están `PENDING VERIFICATION`.

## Archivos

- Primarios: `assets/brand/logos/primary/`.
- Monocromáticos: `assets/brand/logos/monochrome/`.

## Elección por contraste

- Morado, turquesa o amarillo: utiliza la variante que preserve contraste con el fondo y el contexto de campaña.
- Negra: superficies claras o documentación monocromática.
- Blanca: superficies oscuras.

## Prohibiciones

- No estirar, comprimir, rotar o recortar.
- No alterar colores internos.
- No reconstruir “Algorithmics” ni el descriptor con texto editable.
- No añadir sombras, contornos o efectos como parte permanente del logo.
- No usar una versión de baja resolución cuando exista el archivo oficial adecuado.
