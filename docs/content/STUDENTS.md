# Comunicación para estudiantes

## Niños

Usa proyectos, personajes, animaciones, retos y descubrimiento. Mantén instrucciones simples y visuales sin tratar al público como incapaz.

## Adolescentes

Usa autonomía, herramientas, creación de videojuegos o aplicaciones, interfaces, código legible y resultados compartibles. Evita estética demasiado infantil.

En ambos casos, muestra creación y aprendizaje, no únicamente consumo de videojuegos o pantallas.
