# Guía de CTA

| Objetivo | CTA base |
|---|---|
| Expectativa | Muy pronto |
| Tráfico | Conoce más |
| Mensajes | Escríbenos |
| Leads | Solicita información / Regístrate |
| Ventas | Reserva / Inscríbete, si el flujo está confirmado |

El CTA visual, el botón de la plataforma y el destino deben expresar la misma acción. Teléfonos, enlaces y formularios son datos variables y se verifican antes de publicar.
