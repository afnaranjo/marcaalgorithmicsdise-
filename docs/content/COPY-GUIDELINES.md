# Guía de copy

## Estructura recomendada

1. Hook relevante para la audiencia.
2. Cambio o beneficio concreto.
3. Evidencia, mecanismo o proyecto.
4. Programa y público.
5. CTA alineado con el destino.

## Principios

- Un mensaje dominante por pieza.
- Frases breves y específicas.
- Diferenciar dato estable de dato temporal.
- No inventar precios, edades, horarios, sedes, métricas o testimonios.
- “De consumidor a creador” es un territorio estratégico, no una frase obligatoria en cada pieza.
