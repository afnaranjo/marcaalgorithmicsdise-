# Guía de copy

## Estructura recomendada

1. Hook relevante para la audiencia.
2. Cambio o beneficio concreto.
3. Evidencia, mecanismo o proyecto.
4. Programa y público.
5. CTA alineado con el destino.

## Principios

- Un mensaje dominante por pieza.
- Frases breves y específicas.
- Diferenciar dato estable de dato temporal.
- No inventar precios, edades, horarios, sedes, métricas o testimonios.
- “De consumidor a creador” es un territorio estratégico, no una frase obligatoria en cada pieza.
- Los aprendizajes de campañas históricas se reutilizan como estructuras, no como copy obligatorio ni como datos vigentes.

## Territorios de mensaje aprobados

### Consumidor → creador

Transformación central: pasar de usar/jugar con tecnología a construir con ella.

Ejemplos de dirección:

- “CREAR > CONSUMIR”.
- “Tu hijo puede usar tecnología. También puede aprender a crearla.”
- “Que no solo juegue. Que aprenda cómo funciona.”
- “De jugar a crear.”

No repetir siempre la misma frase; conservar la transformación.

### Lo que parece vs. lo que desarrolla

Alcance: `CAMPAIGN / REFERENCE`.

Estructura validada para conversación con padres:

1. presentar un prejuicio reconocible sobre programación/juego;
2. contrastarlo con una habilidad observable;
3. mostrar proyecto/evidencia;
4. cerrar con el programa/CTA.

Prejuicios históricos usados como punto de partida:

- “solo está jugando”;
- “más tiempo pegado a una pantalla”;
- “no sirve para la vida real”;
- “hacer jueguitos”;
- “actividad para entretenerlo”;
- “programar es muy complicado”.

Contrastar con pensamiento lógico, concentración, creatividad, resolución de problemas, autonomía, seguridad para presentar ideas y mentalidad de crecimiento.

Regla: el contraste puede ser provocador, pero no debe culpabilizar, avergonzar ni asustar a padres o estudiantes.
