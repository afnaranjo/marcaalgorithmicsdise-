# Herramientas

## Diseño

- Adobe Photoshop, Illustrator o Express cuando estén autorizados.
- Figma mediante la conexión oficial correspondiente.

## Presentaciones

- PowerPoint o Google Slides.
- Artifact Tool incluido con Codex para generación programática local.

## IA y automatización

- Codex y skills locales del proyecto.
- Generación de imágenes o video solo mediante herramientas autorizadas.

## Memoria y navegación

- Obsidian para abrir la raíz completa del repositorio como vault.
- `00-inicio.md` como panel principal y `config/assets/catalog.json` como inventario técnico de activos.

## Desarrollo

- Git y GitHub con Credential Manager, SSH o integración oficial.
- Git LFS para PPTX y maestros gráficos o audiovisuales pesados definidos en `.gitattributes`.
