# Configuración en macOS

1. Clona el repositorio y abre su raíz en Codex.
2. Ejecuta `git lfs install` y después `./scripts/setup.sh`.
3. Instala Montserrat con Font Book solo si la aplicación de diseño lo requiere.
4. En Obsidian, elige **Open folder as vault** y selecciona la raíz del repositorio. Empieza en `00-inicio.md`.
5. Ejecuta `./scripts/validate.sh` antes de entregar o preparar un commit.

No copies llaveros, perfiles, tokens o credenciales al repositorio.
