# Requisitos

- Git, Git LFS y acceso autorizado al repositorio oficial.
- Codex App, CLI o extensión con lectura de `.agents/skills`.
- PowerPoint o motor compatible para revisar PPTX.
- Herramientas de diseño autorizadas por el equipo.
- Fuentes Montserrat incluidas en `assets/brand/fonts/montserrat/`.

Las integraciones externas requieren autorización individual. No guardes credenciales en el repositorio.

Git LFS gestiona `pptx`, `psd`, `psb`, `ai`, `mp4` y `mov`. Instálalo antes de añadir archivos maestros de estos tipos.
