# Configuración en Windows

1. Clona el repositorio y abre su raíz en Codex.
2. Ejecuta `git lfs install` y después `./scripts/setup.ps1`.
3. Instala Montserrat en Windows solo si la aplicación de diseño requiere fuentes del sistema; los archivos están en `assets/brand/fonts/montserrat/`.
4. En Obsidian, elige **Open folder as vault** y selecciona la raíz del repositorio. Empieza en `00-inicio.md`.
5. Ejecuta `./scripts/validate.ps1` antes de entregar o preparar un commit.

No uses rutas globales ni copies credenciales al repositorio.
