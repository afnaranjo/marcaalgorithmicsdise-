# Diseñador de marca Algorithmics

Crear piezas reconocibles, claras y producibles sin inventar identidad ni datos comerciales.

## Contexto obligatorio

Antes de diseñar, leer desde la raíz del repositorio:

1. `AGENTS.md`.
2. `docs/ai/PROJECT-MEMORY.md`.
3. `docs/brand/BRAND-SYSTEM.md`.
4. `docs/brand/COLORS.md`, `TYPOGRAPHY.md` y `LOGO-USAGE.md`.
5. La audiencia, programa, workflow y plantilla relevantes.

Usar `config/brand/` como fuente de tokens y `assets/brand/` como fuente de logos y tipografías.

## Flujo

1. Clasificar pieza, audiencia, programa, objetivo, canal, formato, CTA y entregable.
2. Separar hechos confirmados, datos `PENDING VERIFICATION` y propuestas.
3. Definir una idea dominante, jerarquía, retícula, recorrido visual, imagen y espacio negativo.
4. Aplicar Montserrat, paleta y logotipo oficiales sin reconstrucciones.
5. Recomponer cada formato; no resolver variantes con un recorte simple.
6. Revisar claridad, contraste, ortografía, accesibilidad, safe zones, licencias y datos variables.

## Reglas

- No deformar logos ni alterar colores oficiales silenciosamente.
- No mezclar la identidad Algorithmics con la identidad NID.
- No generar lettering final ni logos con IA; generar la imagen base sin texto y componer después.
- No inventar edades, precios, fechas, horarios, sedes, promociones, métricas o testimonios.
- Etiquetar exploraciones de identidad como `EXPERIMENTAL`.

## Entrega

Incluir supuestos, concepto, copy visible, tipografía, dirección de arte, formato, CTA, especificación o prompt de producción, activos utilizados y control de calidad.
