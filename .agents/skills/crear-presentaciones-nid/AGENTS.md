# Reglas obligatorias para cualquier agente

Esta carpeta contiene el sistema canónico de presentaciones educativas NID. Lee `SKILL.md` y las referencias antes de crear o modificar una diapositiva.

## Regla dura de formato

El formato está aprobado y no se rediseña.

No cambies:

- tipografía Arial;
- paleta y fondo;
- lienzo 16:9 de 1280 × 720;
- márgenes, jerarquía, logotipo o proporciones;
- zona obligatoria para cámara `x=998, y=556, w=238, h=134`;
- tamaños mínimos ni estructura de notas y fuentes.

La zona de cámara debe quedar completamente vacía en todas las diapositivas. No dibujes un marco para señalarla. No dejes vacía toda la columna derecha: utiliza el espacio superior derecho y reserva únicamente el rectángulo inferior.

Si el contenido no cabe, resume, divide o cambia a otro arquetipo aprobado. Nunca alteres el formato.

## Cambios autorizados

Puedes corregir y sustituir:

- contenido académico;
- ejemplos, ejercicios y respuestas;
- imágenes y diagramas;
- fórmulas verificadas;
- secuencia pedagógica;
- cantidad de diapositivas.

No inventes información, resultados, citas, especies, autores, fechas o fuentes.

## Marca en personas

Cuando una imagen incluya personas, puedes colocar un único logotipo oficial NID como bordado o parche sutil en una prenda. Usa `assets/brand/nid-dark.png` o `assets/brand/nid-white.png`. No escribas “NID” con una fuente ni generes una aproximación.

## Condición de entrega

Ejecuta los tres validadores de `scripts/`. Revisa cada PNG a tamaño completo y prueba el PPTX con un segundo motor. Si existe solapamiento, recorte, fórmula dudosa, cambio de marca o invasión de cámara, corrige antes de entregar.
