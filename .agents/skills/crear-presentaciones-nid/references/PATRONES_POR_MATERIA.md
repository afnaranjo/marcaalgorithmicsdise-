# Patrones por materia

## Modo A — Procedimental y técnico

Usa para Matemática, Física cuantitativa, Química de cálculo, Estadística y Programación.

Secuencia preferida:

1. intuición o problema;
2. metodología;
3. fórmula o regla;
4. ejemplo resuelto paso a paso;
5. cuatro ejercicios con respuesta;
6. cuatro ejercicios sin respuesta visible;
7. síntesis.

Reglas:

- La resolución es el visual principal.
- Renderiza ecuaciones con LaTeX.
- Verifica resultados, dominio, restricciones, signos y unidades.
- Nunca escribas fórmulas complejas como texto lineal si requieren notación matemática.
- Evita fotografías decorativas.

## Modo B — Científico y visual

Usa para Biología, Anatomía, Ecología, Ciencias Naturales, Geología y Astronomía.

Secuencia preferida:

1. visual científico dominante;
2. pregunta de observación;
3. escala o ubicación;
4. estructura;
5. función;
6. proceso;
7. comparación;
8. reconocimiento con un visual nuevo;
9. síntesis estructura → función → consecuencia.

Reglas:

- Distingue fotografía, microfotografía, ilustración y esquema.
- Verifica anatomía, especies, escalas, rótulos y orientación.
- Sustituye cualquier imagen generada que pueda inducir un error científico.
- Alterna visual, proceso, comparación y recuperación activa.

## Modo C — Verbal y humanístico

Usa para Lengua, Literatura, Razonamiento Verbal, Historia, Filosofía y Estudios Sociales.

Reglas:

- Usa una imagen potente para contexto, atmósfera, época, escena o metáfora.
- Mantén fragmentos cortos y legibles.
- Separa hecho, interpretación e hipótesis.
- Registra autor, obra y procedencia cuando utilices material externo.
- Prefiere ejemplos originales cuando no se requiera citar una obra.
- Evita páginas de texto continuo.

## Modo D — Idiomas y memoria conceptual

Usa para Inglés, vocabulario, gramática, taxonomías y clasificaciones.

Secuencia preferida:

1. uso real antes de la regla;
2. regla de decisión;
3. estructura afirmativa;
4. variación o contraste;
5. error frecuente;
6. ejemplo resuelto;
7. práctica guiada;
8. práctica autónoma;
9. producción oral o escrita.

Reglas:

- Alterna reconocimiento, comparación y producción.
- Incluye ejemplos naturales.
- Señala errores típicos sin saturar.
- Mantén instrucciones breves y consistentes con el nivel del estudiante.
