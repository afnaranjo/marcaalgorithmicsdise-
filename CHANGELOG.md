# Changelog

Los cambios significativos del sistema se registran aquí.

## 2026-08-25

### Added

- Constitución operativa y memoria inicial del proyecto.
- Sistema base de marca, contenido, audiencias, privacidad y workflows.
- Tokens reutilizables de color, tipografía y formatos.
- Logos oficiales y familia Montserrat entregados por el usuario.
- Skills locales para marca, copywriting, redes, campañas y presentaciones NID.
- Scripts de configuración y validación local.
- Reglas Git LFS para presentaciones y maestros binarios pesados.
- Vault de Obsidian en la raíz del repositorio con panel de inicio, catálogo visual, memoria operativa, plantillas y bitácora.
- Catálogo técnico de logos, tipografías y presentaciones NID en `config/assets/catalog.json`.
- Bandeja `assets/inbox/` para clasificar nuevos recursos antes de incorporarlos al sistema oficial.
- Paleta Algorithmics de cuatro colores fijada como regla dura con Pantone, HEX, RGB, HSB y CMYK aprobado desde capturas.
- Frambuesa `PANTONE 184 C` / `#F44C75` incorporada a tokens, memoria, catálogo y validadores.
- Revisión separada del manual HTML para conservarlo como guía sin elevar automáticamente sus demás contenidos a reglas oficiales.

### Changed

- Los logos recibieron nombres semánticos y rutas canónicas.
- La skill de presentaciones NID se adaptó al runtime de Codex en Windows sin alterar sus archivos visuales protegidos.
